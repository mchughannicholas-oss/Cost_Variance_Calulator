======================================================================
PROJECT REQUIREMENTS SPECIFICATION
Project Name: Financial Variance Calculator (Streamlit Web Application)
Language: Python 3.10+
UI Framework: Streamlit
======================================================================

1. PROGRAM OVERVIEW
-------------------
The application is a web-based financial dashboard built with Streamlit.
It dynamically prompts users for Actual Cost and Budgeted Cost across 
key accounting categories, passes raw inputs to a pure Python core analytics 
engine, computes numerical cost variances, evaluates performance status 
(Favorable/Unfavorable), and renders an interactive accounting ledger report.


2. FUNCTIONAL REQUIREMENTS
--------------------------
[FR-01] Category Management
        - Maintain target expense categories:
          "Material Cost", "Labor Cost", "Overhead Cost".

[FR-02] Dynamic Web UI Input Widgets
        - Render numerical input fields (`st.number_input`) grouped in 
          two-column layouts per expense category for user entry:
          1. Actual Cost ($) [min_value=0.0]
          2. Budgeted Cost ($) [min_value=0.0]

[FR-03] Variance Analytics Engine (`core_analytics.py`)
        - Compute raw cost variance using the formula:
          Variance = Actual Cost - Budgeted Cost
        - Evaluate performance status based on accounting standards:
          IF Variance <= 0 THEN Status = "FAVORABLE"
          IF Variance > 0  THEN Status = "UNFAVORABLE"

[FR-04] Data Structure & Processing Pipeline
        - Maintain list-based state collection for inputs (`actual_costs`, 
          `budgeted_costs`, `expense_categories`).
        - Process data via `process_all_categories()` and map output records 
          into a list of dictionaries containing:
          Category, Actual Cost, Budgeted Cost, Variance, Status.

[FR-05] Interactive Web Ledger Output
        - Trigger analytics processing upon clicking a submission button (`st.button`).
        - Render a success notification (`st.success`) upon calculation completion.
        - Display the complete variance report table using Streamlit's native 
          interactive dataframe component (`st.dataframe`).


3. TECHNICAL CONSTRAINTS & ARCHITECTURE
---------------------------------------
[TR-01] Core Logic Portability
        - Keep `core_analytics.py` strictly zero-dependency using Python 
          Standard Library data structures (lists, dicts, math utilities).

[TR-02] UI Framework & Minimal Dependencies
        - Utilize Streamlit (`streamlit>=1.30.0`) for browser-based interface 
          and rendering.
        - Avoid unnecessary dependencies (e.g., pandas is not required as 
          `st.dataframe` natively parses lists of dictionaries).

[TR-03] Version Control & Environment Isolation
        - Maintain isolated execution via a native Linux Virtual Environment (`.venv`).
        - Exclude environment folders, byte-code, and system artifacts via `.gitignore`.
